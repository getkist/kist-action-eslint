# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.25] - 2026-08-01

### Changed

- Bumped `eslint` to `^10.8.0`
- Bumped `@types/node` to `^26.1.2`
- Bumped `typescript-eslint` (`@typescript-eslint/eslint-plugin`, `@typescript-eslint/parser`) to `8.65.0`
- Bumped `ts-jest` to `^29.4.12`
- Bumped `typedoc` to `0.28.20`
- `engines.node` is now `>=22.0.0`

## [1.0.0] - 2025-02-08

### Added

- Initial release
- `LintAction` for ESLint linting with TypeScript support
- Configurable target files via glob patterns
- Optional auto-fix mode
- Custom ESLint config file support
- TypeScript support with full type definitions
